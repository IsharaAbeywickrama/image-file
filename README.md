# image-file

The Super Mart POS & Inventory Management System is a comprehensive desktop software solution designed to modernize retail store operations. Traditional manual bookkeeping and legacy POS systems often lead to operational inefficiencies, calculation errors, and poor stock visibility. This project integrates point-of-sale billing, automated inventory management, category organization, and sales data analytics into a single, user-friendly platform. Built using Python, CustomTkinter, and SQLite, the system guarantees high performance, robust security through authentication, and actionable insights via visual dashboards to optimize daily retail workflows. 

Python | SQLite
